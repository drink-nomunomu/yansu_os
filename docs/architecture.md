# YansuOS アーキテクチャ

## システム構成

YansuOSは、複数のモジュールから構成されるモジュラー設計を採用しています。

## ソースコード構造

```
src/
├── main.rs          # エントリーポイント（efi_main関数）
├── lib.rs           # ライブラリクレートのルート
├── allocator.rs     # メモリアロケータ
├── graphics.rs      # グラフィック描画システム
├── init.rs          # システム初期化
├── print.rs         # 出力・デバッグ機能
├── qemu.rs          # QEMU固有の機能
├── result.rs        # エラーハンドリング
├── serial.rs        # シリアル通信
├── uefi.rs          # UEFI API ラッパー
├── x86.rs           # x86アーキテクチャ固有機能
└── test_runner.rs   # テストランナー
```

## 主要コンポーネント

### 1. UEFI層 (`uefi.rs`)

UEFIファームウェアとのインターフェースを提供します。

**主要機能:**
- EFI System Table の操作
- Graphics Output Protocol によるVRAM制御
- メモリマップの取得と解析
- UEFI Boot Services の利用

**主要構造体:**
- `EfiSystemTable`: UEFI システムテーブル
- `EfiGraphicsOutputProtocol`: グラフィック出力プロトコル
- `EfiMemoryDescriptor`: メモリ記述子
- `VramTextWriter`: VRAM直接書き込みテキストライター

### 2. グラフィックシステム (`graphics.rs`)

画面描画とビットマップ操作を担当します。

**主要機能:**
- ビットマップ描画インターフェース (`Bitmap` trait)
- 矩形塗りつぶし (`fill_rect`)
- テストパターン描画 (`draw_test_pattern`)
- フォントレンダリング

**描画プリミティブ:**
- ピクセル単位の描画
- 矩形領域の塗りつぶし
- 安全性チェック付きの座標アクセス

### 3. 初期化システム (`init.rs`)

システムの基本ランタイム環境を構築します。

**初期化プロセス:**
1. UEFI Boot Services の利用
2. メモリマップの取得
3. 基本ランタイム環境のセットアップ
4. システムリソースの初期化

### 4. 出力システム (`print.rs`, `serial.rs`)

デバッグ出力とロギング機能を提供します。

**出力方式:**
- シリアルポート経由のデバッグ出力
- VRAM直接書き込みによる画面出力
- 構造化ログ出力（info!, warn!, error! マクロ）
- hexdump機能によるメモリダンプ

### 5. x86システム層 (`x86.rs`)

x86_64アーキテクチャ固有の低レベル機能を提供します。

**主要機能:**
- CPU制御命令（HLT命令）
- システムレジスタアクセス（CR3レジスタ読み取り）
- ページテーブル操作準備

### 将来の拡張予定

- 仮想メモリシステム

## 起動シーケンス

1. **UEFI起動**: ファームウェアがYansuOSをロード
2. **エントリーポイント**: `efi_main`関数が実行開始
3. **システム初期化**: 
   - VRAM初期化
   - グラフィックモード設定
   - メモリマップ取得
4. **メイン処理**:
   - 画面クリア
   - テストパターン描画
   - システム情報表示
5. **無限ループ**: HLT命令でCPU待機

## エラーハンドリング

- `Result<T>` 型による構造化エラー処理
- パニックハンドラーによる致命的エラー処理
- QEMUデバッグ出力による診断情報

## テスト機能

- カスタムテストフレームワーク
- ユニットテスト実行環境
- QEMUでの自動テスト実行

## 設計原則

1. **安全性優先**: Rustの型システムを活用したメモリ安全性
2. **モジュラー設計**: 機能ごとの明確な分離
3. **UEFI準拠**: 標準的なUEFI仕様への準拠
4. **デバッグ重視**: 豊富なデバッグ出力とログ機能
