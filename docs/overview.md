# YansuOS 概要

## YansuOSとは

YansuOSは、Rustプログラミング言語で開発されたUEFI（Unified Extensible Firmware Interface）ベースの実験的オペレーティングシステムです。現代的なシステムプログラミング技術を用いて、安全性と性能を両立したOSの実装を目指しています。

## 主な特徴

### 1. UEFI起動
- レガシーBIOSではなく、現代的なUEFI仕様に基づいた起動プロセス
- EFI System Tableを通じたシステムリソースへのアクセス
- 64ビットx86アーキテクチャをターゲット

### 2. Rust言語による実装
- メモリ安全性を言語レベルで保証
- `#![no_std]`環境での低レベルシステムプログラミング
- ゼロコスト抽象化による高性能な実装

### 3. グラフィカル出力
- UEFIグラフィックプロトコルを使用した画面描画
- ビットマップベースの描画システム
- カスタムフォントレンダリング機能

### 4. メモリ管理
- UEFIメモリマップの解析と表示
- ページベースのメモリ管理準備
- x86ページテーブル（CR3レジスタ）の読み取り

## 現在の実装状況

YansuOSは現在、基本的なブートローダーとして機能しており、以下の機能が実装されています：

- UEFI環境での起動とシステム初期化
- シリアル出力によるデバッグログ出力
- グラフィカルな画面表示とテストパターン描画
- メモリマップの取得と解析
- 基本的なx86システム情報の取得

## 技術スタック

- **言語**: Rust (2021 edition)
- **ターゲット**: x86_64-unknown-uefi
- **エミュレータ**: QEMU with OVMF UEFI firmware
- **開発ツール**: cargo, rustc
- **デバッグ**: シリアル出力とQEMUログ

## 用途と目標

YansuOSは以下の目的で開発されています：

1. **教育目的**: OSの内部動作理解のためのリファレンス実装
2. **技術研究**: Rustによる低レベルシステムプログラミングの探求
3. **実験プラットフォーム**: 新しいOS機能やアルゴリズムのテストベッド
